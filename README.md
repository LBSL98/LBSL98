## Selected Work

### FORJA — Reproducible Benchmarking Framework for Graph Partitioning

Experimental framework for benchmarking and algorithm selection in graph partitioning.

The project combines **combinatorial optimization, graph algorithms, metaheuristics, experimental engineering and machine learning**. It integrates METIS and KaHIP with Simulated Annealing, Tabu Search, Iterated Local Search and GRASP under a common experimental protocol.

The final experimental campaign evaluated real and synthetic graphs under multiple partitioning configurations and time budgets, and used interpretable CART models to investigate instance-dependent algorithm selection.

**Key topics:** Combinatorial Optimization · Graph Partitioning · Metaheuristics · Algorithm Selection · Machine Learning · Python · Rust

[View repository](https://github.com/LBSL98/Heuristic_Benchmarking_Framework)

---

### ESP32-S3 + W5500 Ethernet Base

Embedded networking firmware for an **ESP32-S3 + W5500 Ethernet** node using ESP-IDF.

The project focuses on explicit system lifecycle, SPI ownership, Ethernet bring-up, DHCP, UDP communication, readiness states, observability and separation between hardware, network infrastructure and application services.

**Key topics:** Embedded Systems · Firmware · ESP-IDF · Ethernet · SPI · UDP · Systems Integration

[View repository](https://github.com/LBSL98/w55100_ESP32)

---

### Connected Graph Partitioning

Experimental research project on connected graph partitioning with fixed-*k* constraints, constructive heuristics and local-search refinement.

The repository includes a reproducible experimental protocol, validation scripts, benchmark artifacts and an audit trail for the results used in the associated research work.

**Key topics:** Graph Algorithms · Combinatorial Optimization · Heuristics · Experimental Benchmarking · Python

[View repository](https://github.com/LBSL98/connected-graph-partitioning-pa)
